# 8界風記 v1.6.0｜遊び方と仕様確認

統合版 26.60 系以上を対象にした、ビヘイビアパックとリソースパック同梱のアドオンです。配布用 ZIP を解凍し、中の `8界風記.mcaddon` を Minecraft で開いて、ワールド設定で両パックが有効か確かめてください。旧版の UUID、訪問先 ID、帰還先、記録、装備 ID は引き継ぎます。既存ワールドで試すときは先にコピーを作ってください。市場・井戸などの地形への追加は未生成の拠点に限ります。

## v1.6.0 の優先度と実装

| 優先度 | 実装 | 遊び方 |
| --- | --- | --- |
| P0：進行・ワールドの安全 | 地続きの八界本街道 | 「ガイド本 → 旅の地図 → 地続きの八界本街道」。草原の村から東へ進み、霧の書庫・砂の迷宮・氷の鏡湖・鍛冶場・地下庭園・浮島・終着駅を、転送せずに歩いて巡れます。隣の区画は近づくと配置されます。配置予定地にブロックがある場合は中止します。旧8界と旧街道はそのまま残します。 |
| P1：村の暮らし・探索報酬 | 日替わりの納品依頼と本街道の踏破報酬 | 村人と鐘のある集落で「村の集落台帳 → 日替わりの納品依頼」。指定の小麦、魚、鉱物などを納めると、備蓄・信頼度が上がり、エメラルド1個がもらえます。プレイヤーは1日1回、村は1日2件。8つの本街道の記録石を読んだら、本街道のメニューから初回報酬として離島の通行札を受け取れます。旧本界の訪問順は変更しません。 |
| P2：遺跡調査の精度 | 複数の手掛かりを照合 | エンド、ネザー要塞と砦、海底神殿の調査では、素材ブロック単体での誤判定を減らしました。図鑑の新しい手掛かりを確認してください。エンドのゲートウェイと帰還口は引き続き直接調べられます。調査済みの記録は失われません。 |

本街道の終着駅は徒歩ルートの再構成です。過去・未来へ走る列車は、従来どおり元の時の終着駅から利用します。離島や風土図鑑の展示へは、従来の旅の地図から向かえます。

## v1.3.0 で増えた遊び

- **醸造**：ガラス瓶＋グロウベリーで「薄明の薬液」を作り、通常の醸造台の瓶スロットに入れます。水の結晶を材料スロットに、ブレイズパウダーを燃料にすると魔力の薬になります。しゃがんで使う旧方式の醸造も残しました。
- **属性刻印書**：本を持ってしゃがみながらエンチャント台を使い、対応する結晶2個で刻印書を作ります。刻印書を持って同じ台を使うと、持ち物の剣へ写せます。通常のエンチャントと耐久値は残ります。剣を直接刻印する従来の操作も可能です。
- **遺跡の仕掛け**：ガイド本で目印を調べてから、時渡りの羅針盤（コンパス＋風記の断片＋時の結晶）を目印に向けて使います。15種類にそれぞれ仕掛けと初回報酬があります。古要塞、ネザー、エンドでは、解くと風記の場所へ渡れます。バニラのブロックは置換しません。
- **装備**：全186件に「守護獣の討伐報酬」「村人への特注」「離島の宝探し」「遺跡の断片交換」のうち1つの製作以外の入手方法を割り当てました。ガイド本の装備図鑑に個別の入手方法が出ます。村の装備は信頼度3以上で特注、離島は記録石を調べて通行札、遺跡は目印を調べて断片を使います。宝と断片交換は宝箱の中身を差し替えるのではなくガイド本から受け取ります。
- **バニラ装備の愛着度**：剣と斧は対モブ攻撃、弓とクロスボウは矢の命中時に同系統の弓を手に持つこと、ツルハシ・シャベル・斧・クワは適したブロックを壊すこと、防具は装備して敵の攻撃を受けることで成長します。成長値はプレイヤーと装備種別に紐づき、個々の装備に移る値ではありません。
- **魔法と図書館**：「潮騒の図書館」の記録石で魔導書を一度受け取れます。8属性と5種類の合成魔法は発動すると魔法図鑑に記録されます。光は状態異常を浄化し、闇は敵から体力を吸収し、時は敵を強く減速させます。
- **牧場と祭り**：ウシ・ブタ・ニワトリ・ヒツジに餌を与えると、1頭につきゲーム内で1日1回素材がもらえます。繊維と育てのしるし、土でも季節の花壇を作れます。季節2日目の釣り祭りで4種の限定魚を釣れ、村の収穫市で交換できます。
- **土組み自動炉**：西の樽に燃料と砂・粘土・生肉など、東に出力用の樽を置きます。出力先が満杯なら何も消費しません。新規生成の未来の工場にも置かれます。

## 追加機能の入口

- **八界街道**：「ガイド本 → 旅の地図 → 徒歩で巡る八界街道」。東西に続く道で、草原から時計台の小駅まで8区画を歩いて巡れます。次の区画は境目に近づくと準備され、歩いて訪れた区画は地図に登録されます。本来の8界も従来どおり別の行き先として残ります。
- **連絡船**：灯台の港、赤灯の干潟、影砂のオアシス、霜灯の入り江、瑠璃水の洞で「港の船便と市」。目的地の界を訪問し、離島の通行札を用意してください。「船上で過ごす」にすると、停泊した船の上で釣り・調理・交易ができます。出航後に降りると移動を中止し、安全な足場があれば岸に戻ります。
- **集落台帳**：村に「風記の集落鐘」を設置するか、村人の近くで普通の鐘をしゃがんで使います。鐘から水平11ブロック内に壁、足止め罠、鐘より3〜5ブロック高い見張り台の標、加工機を置くと守りが上がります。設備の読み取りは数十秒かけて実行されます。
- **村の成長と祭り**：鐘から24ブロック内の工場が出荷すると備蓄が増え、出荷が止まると守りの稼働ボーナスが消え、住民の生活で備蓄も減ります。守り6以上・備蓄12以上で空きベッドなどの条件を満たすと子どもが増えます。守り4以上・備蓄6以上なら季節2日目に祭りが開かれ、台帳で季節の記念章を受け取れます。職を持つ住民は職業に対応する作業台へ、夕方や危険時は寝床のほうへ向かいます。
- **鉱脈採り機**：西に燃料の樽、東に出力樽を置きます。真下6ブロック以内にある鉄・銅・金の鉱石と風記の結晶鉱が対象。岩や空気を調べ、他のブロックが途中にあれば止まります。出力樽が満杯なら鉱石も燃料も減りません。加工機、圧縮機、選別機、コンベア、採り機には天気や時刻による効率差があります。
- **遺跡調査**：「ガイド本 → バニラの遺跡と風の道」。スポナー、ポータル枠、試練のスポナーなど、15種類の目印を見て調べると物語と断片が記録されます。手掛かりはメニュー内で確認できます。
- **装備の製作**：紙を持ってしゃがみながら作業台を使うと、番号で装備を選べます。全186件に、紙2・鉄インゴット1・指定結晶1・指定欠片1を使えます。剣・斧・弓を持って同じ操作をすると、同じ武器種に作り替える選択肢も出ます。作り替え前の装備・刻印・エンチャントは戻りません。
- **花壇・天候・表示**：季節の花壇は春夏秋冬で形と色が変わり、条件の合う近くの作物を少し育てます。地形ごとの霧・砂・雪・強風などは「設定・帰還地点」でオフにできます。左上 HUD が別のリソースパックと競合する場合は、HUD位置を「通常のアクションバー」に変更できます。
- **時の列車**：第8界「時の終着駅」で「時の列車 → 乗り場へ移動」。過去の駅村・未来の工場を選ぶと車両に乗れます。途中で降りるか進路がふさがれた場合は移動を中止します。

## 確認範囲

同梱 JSON、アーカイブ、ブロックと地形の参照、ファイルの存在、スクリプトの型、演出・PBR素材の数、模擬ワールドの挙動を検査する構成です。実機でのクライアント描画、コントローラー操作、警告ログの確認とは別です。

[Microsoft Learn のカスタムディメンション仕様](https://learn.microsoft.com/en-us/minecraft/creator/documents/scripting/custom-dimension-api-tutorial?view=minecraft-bedrock-stable)では、カスタムディメンションの JSON ジェネレーターに `void` を使い、地形はパック側から配置します。[標準エンチャント一覧API](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/enchantmenttypes?view=minecraft-bedrock-stable)には参照用の `get` と `getAll` があり、新種の登録方法は掲載されていません。[Vibrant Visuals のテクスチャセット仕様](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/texturesetsreference/texturesetsconcepts/texturesetsintroduction?view=minecraft-bedrock-stable)に従い、通常描画向けの色画像も同梱しています。
