- 容量を超えると全体停止。矛盾した歯車ループ、動力源同士の回転数不一致、4〜128 RPMの範囲外、未読込境界や探索上限96ノードも停止します。隣接する機械も互いに動力を伝えます。しゃがんで空手で機械・軸・歯車箱を触ると状態、RPM、負荷／容量を表示します。読み込み状態・表示は実機未確認です。
- 16 RPMで約40tick、32 RPMで約20tick、8 RPMで約80tickが加工間隔の目安。実際はブロックtickの間隔・天候・夜間条件により遅くなります（最短10tick）。動力源がないと従来どおり一部機械は燃料で動き、圧縮機・選別機は従来の無燃料動作を維持します。接続回路が過負荷・矛盾・未読込なら燃料への逃げ道もなく停止します。高所の風力加工機の従来の独立風力も維持します。

**実用例**：破砕機で各界の結晶1個を同属性の欠片2個に加工し、圧縮機で欠片2個＋アメジストの欠片1個から結晶を作れます。破砕機・圧縮機・選別機や搬送管を樽でつなぐと素材整理やライン作りに使えます。採掘機や自動炉にも動力を供給できます。増速／減速を比較し、機械を増やす場合は同じ回転数・向きの動力源を追加してください。

### 追加生物と八界王の攻撃安全性（試作）

敵対する追加生物と既存ボス「終焉の八界王」のスクリプト攻撃は、固定された輪と約2秒の予告を出します。予告の表示に失敗した場合や攻撃の処理が遅れた場合はその攻撃を中止し、ピースフルに変更された場合も保留中の敵対技を取り消します。一般生物の範囲技は予告の輪の中だけに命中します。ダメージが拒否された場合、その命中に伴う鈍足・毒・吹き飛ばし・吸命などは適用しません（八界王の一部の技には、ダメージのない外側の範囲に状態異常だけを与える挙動があります）。追跡紋は状態異常に少量のダメージを伴う仕様に変更しました。

これは**スクリプト固有技のみ**の変更で、エンジンの通常近接攻撃には適用しません。描画設定や通信遅延によって予告が実際に見えるか、攻撃・トーテム・パリィ・複数人の処理順は統合版で未検証です。生物の動きや各技の個性も引き続き調整が必要です。

### FUSHIのトーテムと必殺技（試作）

以下の過去版の説明より、武器の必殺操作は冒頭の7.1.25を優先してください。

**重要：バニラの復活機構そのものではなく、ダメージ直前の値から致命傷を推定するスクリプトです。** 防具・吸収ハート・他アドオンやイベント順の影響で、実際には致命傷でないのに消費したり、逆に発動しない可能性があります。消費は次の安全な処理に延期され、直前にアイテムが移動・消失した場合は元のダメージを再適用しますが、割り込みやログアウトを含め完全な原子性は保証できません。バニラの画面中央のトーテム演出もありません。**実機検証が済むまで、死亡を確実に防ぐ手段として頼らないでください。** 大切なワールドはバックアップし、まずテストワールドで確認してください。

**必殺「あきらめない」**（護符版。武器版は上記7.1.24を参照）：アメジストの欠片＋風と時の結晶で「不屈の護符」を作り、スタミナが1〜20かつ魔力が0〜20のとき使うと、見通しのある8ブロック以内の敵最大6体に20ダメージと複合効果を与えます。スタミナを全消費し、魔力や護符は消費しません。発動から1秒は通常のダメージを防ぎ、対応するスクリプト技の追加効果も避けます。奈落・`/kill`・直接体力変更や他アドオンの独自効果は防げません。敵がいない場合は消費せず、成功後は30秒の再使用待ちがあります。操作・判定・バランスは実機未検証です。

壁登りは採用しません。

### 戦闘演出と風紋連撃（試作）

資料から「動き・軌跡・音の重ね合わせ」「蓄積を使った判断」という一般的な考え方を参考にし、武器・スキル名やコード、素材は流用せず、8界風記独自の風紋として実装しました。

風記の**剣・斧・槍**で、立ったまま敵にダメージを与えると風紋が1つたまります。命中間隔は0.4秒以上、次の命中まで4秒以内。3つで満ち、最後の命中から6秒間維持します。HUDに残数を表示し、斬撃の風跡・短い音・動きを試作しています。敵はモンスター、管理者、攻撃した界別エンダーマンとFUSHIのチーフに限り、プレイヤー同士の攻撃がOFFの間はプレイヤーへの攻撃ではたまりません。

**二連終撃（旧操作の説明。7.1.25ではしゃがみ＋使用で発動）**：風紋が2つの状態で、しゃがみながら同じ剣・斧・槍の使用を約1.2秒以上長押しして離すと、風紋2つを消費して溜め技の威力を約20%、吹き飛ばしを1.5倍にします。剣は前方最大3体、槍は前方最大2体、斧は見通しのある周囲最大6体が対象です。ボスなどノックバック耐性のある敵は動きません。風紋は敵への実ダメージ命中2回でためるため、空振りはカウントされません。終撃そのものが外れた場合は風紋を消費します。通常近接命中時のスタミナ消費はこの3種類では3、溜め技は8と通常の魔力が必要で、マナ・スタミナ不足や再使用待ちなら発動せず風紋も残ります。防御の消費は別です。HUDに溜め中・離す準備完了を表示します（表示は最大約0.5秒遅れ）。15秒間使用を完了させてしまった場合や、装備・スロット・次元を変えた場合は溜めを中止します。ボタンを離さず溜め切っただけでは発動しません。Bedrock実機での入力イベントと端末別の操作は未確認です。

満ちている間に**同じ武器スロット**で既存の武器スキルを使うと、風紋を消費してスキルの攻撃ダメージを約25%上げ、光の輪を出します。通常攻撃自体に追加ダメージはありません。空振りでも消費し、通常のマナ・スタミナ・再使用時間も必要です。武器やスロット、次元の変更、死亡、離脱で消えます。通常の範囲スキルは中立MOBを巻き込まず、管理者は対象になります。管理者へのパリィ成功時は、同じ攻撃による自動スキル発動を抑えます。

風紋が満ちた状態で**しゃがんだまま武器の使用を約1.2秒以上長押ししてから離す**と、範囲攻撃の代わりに視線方向へ「風紋閃」を放ちます。剣は10、斧は8、槍は13ブロックまでの瞬時判定で、最初の1体に当たり、壁や味方で止まります（OFF中はプレイヤーを傷つけません）。溜め技の通常コストと再使用時間が必要で、空振りでも風紋を消費します。進路が未読み込み、または判定APIが失敗した場合は発動せず消費もしません。見た目は光跡ですが、飛行する弾のエンティティではありません。

**前方防御（試作）**：風記の剣・斧・槍を手に持ち、しゃがむと開始時と以後毎秒スタミナ5を消費し、前方からの近接・飛び道具ダメージを70%軽減します。環境・魔法・背後攻撃は対象外。構えの開始は最大約0.5秒遅れ、使用中はスタミナが自動回復しません。不足すると、しゃがみを解除するまで再開できません。飛び道具の位置を優先し、取れない場合は攻撃者の位置を使います。武器技の使用や近接攻撃も通常どおりスタミナを使うため、防御・溜め・パリィは同時に資源を消費しえます。HUDに防御・風紋・武器技の残り時間を表示します。

**防御解除パリィ（試作）**：盾を装備していないときに風記の剣・斧・槍で有料のガードが始まってからしゃがみを解除すると、約0.3秒間、正面からの対象の近接・飛び道具を1回だけ、スタミナ15で防ぎます。スタミナが足りない場合や、背後・環境攻撃、攻撃者が不明な弾、プレイヤーからの攻撃は対象外です。弾は着弾地点の方向を優先します。防御維持費は別に必要です。画面上の「防御中」を確認してから解除してください。

モンスター、守護獣、八界王、界別エンダーマン、FUSHIチーフ、管理者を対象に、近距離（5ブロック以内・高さ差3以内）で成功した場合は約2秒間の近接ダメージ抑制と鈍足を試作しました。八界王・管理者・チーフ・界別エンダーマンなどの対応済みスクリプト技は待機も入ります。管理者は回復を10秒止めます。遠くの敵の弾を防いでも、遠方の発射者はひるみません。複数人への範囲攻撃では、防いだ本人以外は同じ攻撃を受けます。**バニラAIの移動やすべての攻撃・効果を完全に停止するものではなく、全ボス共通の完成版ひるみではありません。** 既存の「管理者へしゃがみ近接する」試作パリィも引き続き使えます。

**回避ロール（旧仕様の説明。現在の未配布作業では上記の地上専用仕様）**：サバイバルまたはクリエイティブで地上に立ち、しゃがみながら前進入力をいったん離して素早く2回（0.45秒以内）入れると、視線の水平前方へロールします。武器は不要で、スタミナ10を消費し、再使用待ちはありません。動作中の0.5秒は近接・飛び道具・爆発・魔法など指定された攻撃ダメージを回避します。管理者、FUSHIチーフ、界別エンダーマン、追加MOB・八界王のスクリプト技は、回避中の対象へのデバフや押し出しも抑制します。ガードの維持費は別途かかります。
