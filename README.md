### 今回の確認版（7.1.11）：接合・回転・往復と黒曜石

- **移動接合器**：既存の移動フレームにつながる6方向の接合器を追加。名前の方向に接する1ブロックを移動構造物に加えます。通常の石・丸石・板材・ガラス、16色のコンクリート／羊毛／テラコッタ／色ガラス、一部の8界建材、液体タンク・液体管などに対応。対象外のブロックが接合先にある場合は動かず停止。ブロック状態は保存して移動しますが実機未確認。接合器が地面を向くと対応する地面も選ばれるため注意。
- **動力回転台**：上にフレーム等をつなぎ、上から見て90度ずつ右／左または連続回転。接合器も向きを変えて追従し、深層岩・クォーツの柱軸も回転。32ブロックまで、16 RPM時32 SU。展示台・回転扉などに利用できます。滑らかな連続描画ではなく90度刻みです。
- **自動往復**：直線装置に往復モードを追加。原点と8マス先で自動反転し、端で約4秒（16 RPM時）待機。接合した液体タンクの輸送などに使えます。ポンプとの位置や充填速度は実際に確認してください。
- **黒曜石の自動生産**：液体加工槽に水と溶岩のタンクを隣接し、動力と西入力・東出力樽を用意。入力の対応するアイテム加工がない時、溶岩4目盛り＋水1目盛りから黒曜石1個を生産します。満杯・液体不足時は停止。

例：東向き移動装置の東に移動フレーム、さらに東側に「上側」移動接合器、その上に液体タンクを置く。装置に動力をつなぎ、自動往復を選んで離れるとタンクを一緒に運ぶ試作になります。回転台では、上にフレームを置いて横に接合器と建材をつなぎ、台を使って回転方向を選びます。

**重要**：Create同等ではありません。チェストなどの収納ブロック・任意の機械・プレイヤー・生物は運べず、移動と回転は刻み式です。32ブロック上限と空間・エンティティ検査があり、保護領域への対応や完全な衝突防止・クラッシュ時の原子性は保証できません。実機検証前なので、大切なワールドは必ずバックアップし、新規ワールドと少量の素材で試してください。

### 前回の確認版（7.1.10）：溶岩源ポンプ・移動構造物

**溶岩源からの直接吸い上げ**：動力ポンプの背後にバニラの溶岩源を置くと、溶岩源1ブロックを消費し、出力先の空または溶岩タンクへ4目盛り（バケツ1杯）を送ります。単一のタンクに4目盛り以上の空きが必要です。満杯・違う液体・未読込・管の上限超過・動力不足・流れる溶岩では吸いません。水源は従来どおり消費しません。周辺の溶岩は流れることがあり危険です。失敗時の復旧はベストエフォートです。

**動力移動装置（試作）**：6方向の装置と専用「移動フレーム」「移動パネル」を追加。動力装置の向き側の隣に専用ブロックを置き、そこから繋いだ専用ブロックを最大32個まで、最大8ブロック先まで一体で移動します。装置を使って1歩前進／後退、連続前進／後退、停止を選択。連続運転は離れるための待ち時間の後に始まり、16 RPMなら約40 tickごとに1ブロック動きます。動力は16 RPM時32 SU。障害物、動力不足、未読込、上限、近くの人・生物・アイテム等を検出した場合は停止します。スクリプト再起動後は自動再開せず、再操作が必要です。

例：高さ80の平地に東向き装置を置き、その東隣から移動フレームとパネルで壁を組みます。装置の北側に頭上の開いた風力回転機を隣接させ、装置を使って連続前進を選び、構造物から離れます。後退で元の位置まで戻せます。レシピは工業ガイドと作業台の検索で確認してください。

### 前回の確認版（7.1.9）：液体と3軸歯車

**水・溶岩の液体ネットワーク（試作）**：液体管は6方向に接続し、曲がり・上下・分岐ができます。動力ポンプは名前の向きの反対側から、正方向へ送ります。出力先は管をたどった先の液体タンク。管1系統は最大64個、タンクは中継しません。分岐先は近い順・固定順で、空きがあり同じ液体か空のタンクを選びます。タンク容量は8目盛り＝バケツ2杯、状態はブロックに保存されます。しゃがんでタンクに触れると量を表示。**壊すと中の液体は消えます**。

- ポンプは動力必須（16 RPM時16 SU）。入力がタンクなら中身を消費。入力がバニラ水源なら水源を消さず水を供給します。7.1.9当時は溶岩源から吸えませんでしたが、7.1.10で試作しました。
- **液体注入機**（16 SU）：西に入力樽、東に出力樽、隣にタンク。水／溶岩入りバケツを入力すると、同じ液体か空のタンクに4目盛り注入し、空バケツを出力。満杯・種類違いなら停止。
- **液体加工槽**（32 SU）：西入力樽・東出力樽・隣にタンク。空バケツ＋液体4目盛り→水／溶岩バケツ、水1目盛り＋土→泥、水1目盛り＋16色のコンクリートパウダー→同色コンクリート、溶岩1目盛り＋丸石→石。複数タンクは固定順で選択。出力満杯・液体不足なら消費せず停止。
- 既存の洗浄機は、隣に水ブロックがない場合でも隣の水タンクから1目盛りを消費して動作。水ブロック隣接時は従来どおり消費しません。
- **3軸歯車**：従来の東西に加え北南・上下向きの増速／減速歯車箱を追加。既存歯車箱＋火打石で北南、＋羽根で上下。負方向→正方向で増速2倍／減速半分、逆方向では逆比、いずれも逆回転。動力接続は軸の両端のみ。立体表示は追加方向に正しく向かない可能性があります。

例：高さ80で東向きポンプの西に水源、東に液体管をつなぎ、管の先にタンクを置きます。ポンプの南に頭上の開いた風力回転機を設置。別の液体加工槽の西・東に樽を置き、その北にタンク、南に風力回転機を置けば、土や空バケツを加工できます。離れたタンク間は、送り出すタンクの隣に別のポンプが必要です。タンクやバケツの数を小さくして確認してください。

**制約**：液体は管内に保持されず、ポンプごとにタンク間を1目盛りずつ移す簡略モデル。分岐は均等分配ではなく、未読込や上限超過では停止。溶岩の自然吸い上げと専用ブロックの直線移動は7.1.10で試作。液体の地面への放出、他の液体、任意ブロックの可動構造物やCreate全機能は未実装です。動作・描画・保存・失敗時復旧・スマホ負荷はBedrock実機未確認。必ずバックアップし、新規ワールドで少量から試してください。

### 前回の確認版（7.1.6）：動力・立体回転の試作

軸・風力／水力回転機・増速／減速歯車箱の立体部品を、表示専用の非衝突エンティティとクライアント側アニメーションで回す方式に変更しました。実際の機械・インベントリはブロックのままです。回転数を表示へ同期し、停止時は止まります。速度変更・再読込では角度が飛ぶ可能性があり、実際の描画や回転の滑らかさは**実機未確認**です。加工機自体は7.1.6当時、表示切替・粒子のみでした。現行の試作は上記参照。

**動力のルール**（独自の簡略SU。Createとは別物）：
- 風力は高さ64以上かつ上空32ブロックに障害物がないとき16 RPM／容量128 SU、水力は隣接する水で16 RPM／容量192 SU。水流方向・天候による出力差はありません。
- 軸は6方向に接続。増速歯車箱・減速歯車箱は**西（X−）と東（X＋）だけ**接続し、西→東では2倍／半分、逆回転。東→西ではその逆比になります。増速の後に負荷が増え、減速なら負荷が下がる代わりに加工が遅くなります。
- 基準16 RPM時の負荷は、加工機・炉・破砕機・圧縮機32、採掘機64、洗浄機・製材機24、プレス48、選別機16 SU。負荷は接続機械の回転数の絶対値に比例し、入力が空でも予約します。複数の稼働中動力源は回転数・向きが合う場合だけ容量を合算します。
- 容量を超えると全体停止。矛盾した歯車ループ、動力源同士の回転数不一致、4〜128 RPMの範囲外、未読込境界や探索上限96ノードも停止します。隣接する機械も互いに動力を伝えます。しゃがんで空手で機械・軸・歯車箱を触ると状態、RPM、負荷／容量を表示します。読み込み状態・表示は実機未確認です。
- 16 RPMで約40tick、32 RPMで約20tick、8 RPMで約80tickが加工間隔の目安。実際はブロックtickの間隔・天候・夜間条件により遅くなります（最短10tick）。動力源がないと従来どおり一部機械は燃料で動き、圧縮機・選別機は従来の無燃料動作を維持します。接続回路が過負荷・矛盾・未読込なら燃料への逃げ道もなく停止します。高所の風力加工機の従来の独立風力も維持します。

**実用例**：破砕機で各界の結晶1個を同属性の欠片2個に加工し、圧縮機で欠片2個＋アメジストの欠片1個から結晶を作れます。破砕機・圧縮機・選別機や搬送管を樽でつなぐと素材整理やライン作りに使えます。採掘機や自動炉にも動力を供給できます。増速／減速を比較し、機械を増やす場合は同じ回転数・向きの動力源を追加してください。

歯車の設置例（同じ高さ）：西から「風力回転機 → 増速歯車箱 → 軸」と並べ、最後の軸の北または南に破砕機を隣接。その破砕機の西に入力樽、東に出力樽を設置します。風力回転機は上空を空けてください。歯車箱の側面（北・南・上下）は接続しません。

表示専用エンティティは破壊されたブロックの周囲で自動整理を試みますが、チャンクの読み込み・クラッシュ・スクリプト停止時の残留や描画不具合は未検証です。多数設置はスマホの負荷になる可能性があり、機械の処理も完全な原子性を保証できません。新規ワールドと少量の素材で確認し、既存ワールドは必ずバックアップしてください。

### 界渡りのエンダーマンとFUSHI（試作）

### 追加生物と八界王の攻撃安全性（試作）

### FUSHIのトーテムと必殺技（試作）

### 戦闘演出と風紋連撃（試作）

資料から「動き・軌跡・音の重ね合わせ」「蓄積を使った判断」という一般的な考え方を参考にし、武器・スキル名やコード、素材は流用せず、8界風記独自の風紋として実装しました。

風記の**剣・斧・槍**で、立ったまま敵にダメージを与えると風紋が1つたまります。命中間隔は0.4秒以上、次の命中まで4秒以内。3つで満ち、最後の命中から6秒間維持します。HUDに残数を表示し、斬撃の風跡・短い音・動きを試作しています。敵はモンスター、管理者、攻撃した界別エンダーマンとFUSHIのチーフに限り、味方やプレイヤーへの攻撃ではたまりません。

**二連終撃（試作）**：風紋が2つの状態で、しゃがみながら同じ剣・斧・槍の使用を約1.2秒以上長押しして離すと、風紋2つを消費して溜め技の威力を約20%、吹き飛ばしを1.5倍にします。剣は前方最大3体、槍は前方最大2体、斧は見通しのある周囲最大6体が対象です。ボスなどノックバック耐性のある敵は動きません。風紋は敵への実ダメージ命中2回でためるため、空振りはカウントされません。終撃そのものが外れた場合は風紋を消費します。通常近接命中時のスタミナ消費はこの3種類では3、溜め技は8と通常の魔力が必要で、マナ・スタミナ不足や再使用待ちなら発動せず風紋も残ります。防御の消費は別です。HUDに溜め中・離す準備完了を表示します（表示は最大約0.5秒遅れ）。15秒間使用を完了させてしまった場合や、装備・スロット・次元を変えた場合は溜めを中止します。ボタンを離さず溜め切っただけでは発動しません。Bedrock実機での入力イベントと端末別の操作は未確認です。

## テクスチャ作業の記録

`texture_progress.json` は個別・形状加工、共通原画からの加工、簡易図案、追加予定画像を区別して記録しています。`python3 tools/texture_inventory.py` で既存アイテムの差し替え状況を確認できます。全件差し替え済みでも、品質の完成やゲーム内表示を保証しません。追加予定の画像は完成数に含めていません。追加したエンダーマンとFUSHIの画像は暫定で、設計書の追加予定のMOBや装備の専用テクスチャ等は未完成です。界別ガイド・帰還石も画像のみで機能はありません。

画像の切り抜きと128px・マップ作成には `tools/import_item_art.py` を使用しました（`python3 -m pip install -r tools/requirements-art.txt` で Pillow を導入）。加工済み共通原画は `tools/art_templates/` にあります。`tools/render_gear_icons.py`、`tools/render_extra_item_icons.py`、`tools/render_misc_icons.py`、`tools/render_refined_misc.py`、`tools/render_planned_travel_icons.py`、`tools/render_planned_extras.py` の順で再生成できます。番号描画には DejaVu Sans Bold フォントが必要です。元の生成画像はパックに含めていません。

エンダーマンとFUSHIの仮モデル・テクスチャは、Pillow導入後に `tools/create_realm_endermen.py`、`tools/create_fushi_content.py`、`tools/create_warden_content.py` で再生成できます。これらのスクリプトは対応するBP/RPの定義も上書きします。

レギンスのアイコンは `python3 tools/create_leggings_icons.py`、着用画像は `python3 tools/create_leggings_wear.py` で再生成できます（Pillow必要）。他の防具生成器は旧アイコンを上書きするため、実行した場合は最後にこの生成器を実行してください。
